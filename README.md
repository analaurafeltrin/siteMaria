## 💡 Sobre o projeto

Esse projeto tem um lugar especial pra mim: foi o primeiro site que desenvolvi para alguém. Esse alguém é minha irmã, e foi uma honra ela me dar essa oportunidade tão cedo na minha jornada. A proposta era simples — uma página personalizada de links com cupons — mas o significado foi muito além disso.

Foi também o projeto onde comecei a colocar em prática o uso do **Git Bash** para versionamento, tornando esse repositório um marco duplo: primeiro cliente *e* primeiro workflow mais próximo do mundo real.

---

- **CSS3** 
- **JavaScript**

---

## 🎯 Objetivo

Além de entregar um projeto funcional para a minha irmã, esse repositório foi usado para praticar o fluxo de trabalho com **Git via terminal** — commits, push e o processo de manter um histórico de versões organizado. Pequenos passos que fizeram uma diferença enorme no desenvolvimento profissional.
